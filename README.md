# AHP 决策工作台

一个无需安装、可在浏览器中直接运行的层次分析法（AHP）决策工具。它将指标权重、方案评价、一致性检验、子指标筛选和结果排序整合在一个交互式页面中。

线上体验地址：[AHP 决策工作台](https://antilovsky.github.io/AHP-workbench/outputs/ahp-app/)

## 功能

- 单人或群体决策；群体结果可按加权几何平均或加权算术平均汇总
- 基本 AHP 与最低期望水平 AHP
- 最多 15 个评价指标，并支持为指标设置子指标
- 指标、子指标与方案两两比较；使用行几何平均法计算权重
- 自动计算一致性指标 CI、CR；`CR ≤ 0.10` 视为可接受
- 三种独立的矩阵评价方式：Saaty 标度选择、直接填写数值、图形化重要度控件
- 图形控件、标度选择和填写模式之间自动映射已有判断
- 特征值与权重偏差提示，帮助定位可能导致一致性偏低的评分
- 子指标 ABC / 帕累托筛选，并将入选子指标用于方案评价
- 最低期望水平方案参与排序，并标示未达到期望水平的方案或指标得分
- 展示层次结构、指标得分明细与最终排名
- 导出和导入 JSON，以保存、复现或继续既有决策过程

## 使用方法

1. 直接用浏览器打开 `index.html`，或访问上方线上地址。
2. 在“设置”中填写决策名称、候选方案、指标，以及可选的子指标和最低期望水平。
3. 在“指标权重”“子指标权重”和“方案评价”中完成两两比较；每个矩阵可单独切换评价方式。
4. 如使用子指标，在“ABC 筛选”确认参与方案评价的子指标。
5. 在“结果”中查看排名、综合得分和各评价指标的贡献。

## Saaty 标度

两两比较采用 Saaty 1–9 标度：

| 标度 | 含义 |
| --- | --- |
| 1 | 同等重要／具备同等优势 |
| 3 | 较为重要／具备一定优势 |
| 5 | 很重要／具备优势 |
| 7 | 非常重要／具备很大优势 |
| 9 | 极其重要／具备极大优势 |
| 2、4、6、8 | 相邻判断之间的中间值 |
| 1/2 至 1/9 | 表示相反方向的重要程度 |

## 数据与隐私

该工具为纯前端静态页面。填写的数据保留在当前浏览器会话中；如需长期保存，请使用页面中的 JSON 导出功能。导入同一份 JSON 可复现相应的决策过程。
